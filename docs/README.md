# Docs

This folder contains research notes and technical documentation for the Bedrock gyroscope controls idea.

## Notes

- Direct gyroscope access is not currently part of the standard Bedrock Script API.
- Bedrock mobile hardware access is limited compared with desktop modding environments.
- A custom external app + server bridge could be a possible experimental approach, but it is not part of normal add-on workflows.
- A clear feature request could help push the idea forward if the community shows interest.
